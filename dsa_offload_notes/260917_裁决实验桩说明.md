## 2. 探针清单与输出格式

统一开关：`export VLLM_ASCEND_SFA_ADJ_PROBE=1`（默认关闭，关闭时全部探针为零开销空操作）。
输出：C++ 侧走 **进程 stderr**（异步 sink，前缀 `[SFA_ADJ_PROBE]`）；实验③走 Python logger（同样落 stderr/服务日志）。

### 探针 1：写后读可见性（实验①核心，两后端对照）

挂点：每融合层 `inject` 之后、`wait_for_current_kv_writeback` 之前/之后各一次。

```text
[SFA_ADJ_PROBE] stage=host_kv_visibility_pre_join  call=7 layer_id=3 tp_rank=0 dtype=6 numel=1 hash=... values=[2]
[SFA_ADJ_PROBE] stage=host_kv_visibility_post_join call=7 layer_id=3 tp_rank=0 dtype=6 numel=1 hash=... values=[0]
                                            (Mooncake 设备端路径；values=[本帧未落地行数])
[SFA_ADJ_PROBE] stage=host_kv_visibility_hostview_pre_join call=7 layer_id=3 tp_rank=1 mismatches=2/8 first_bad_token=3
                                            (MemFabric host 回调路径；mismatches=未落地数/有效行数)
```

- 测量语义：**本 step 每个 token 的 host 行内容 == 本 step 为它算出的 K/V？**（bf16 按 int16 逐 bit）
- `pre_join` 非零 ⇒ 融合算子将读到未落地行（E1：仅 tp_rank=0 出现；E2：所有 rank 都可能出现）；
- `post_join` 必须恒 0，否则 join 未覆盖写回（修复无效或写错行）；
- **计数跨层累积**（layer0 pre_join 清零）：layer L 读数含 0..L-1 贡献，逐层归因用相邻快照差分；
- Mooncake 测的是算子真正读取的 NPU VA 视图；MemFabric 测的是 host 侧 GVA 视图（算子语义上同址）。

### 探针 2：MTP vs layer0 slot_mapping diff（实验②）

挂点：`offload_new_kv` 内，图捕获时 layer0 与 MTP 层各打一次（replay 经捕获节点逐帧重放）。

```text
[SFA_ADJ_PROBE] stage=slot_mapping_l0  call=5 layer_id=0  tp_rank=0 dtype=4 numel=8 hash=0x... values=[...]
[SFA_ADJ_PROBE] stage=slot_mapping_mtp call=5 layer_id=60 tp_rank=0 dtype=4 numel=8 hash=0x... values=[...]
```

判读：**同 call 序号的两个 hash 不同 ⇒ MTP 层确实使用另一份 slot_mapping ⇒ P0-新（标准分支描述符复用）确诊为真实缺陷**；恒相同 ⇒ P0-新 排除（Fix A 退为无害加固）。采样策略：前 4 次 + 2 的幂 + 每 64 次必打。

### 探针 3：sparse_copy 落地测定（实验③，eager + MemFabric + TP0）

挂点：`_offload_new_kv_on_current_stream` 的 `offload.sparse_copy` 返回后（期望 K/V 在**调用前**已快照到 CPU，比较为纯 host 读，不依赖包含拷贝的流）。

```text
[SFA_ADJ_PROBE] stage=sparse_copy_landing tp_rank=0 rows=8 immediate_mismatch=k:0/v:0 after_sync_mismatch=k:0/v:0 elapsed_ms=0.412
```

判读（直接裁决解释 a）：
- `immediate > 0` ⇒ sparse_copy **返回时数据未落地**（异步原语）⇒ 解释 a 被否证，MemFabric 的"正常"只能靠解释 b/c；
- `immediate == 0` ⇒ **同步/自带 flush 语义** ⇒ 解释 a 确证；
- `after_sync` 恒应为 0（非 0 说明比较方法本身有问题）。

### 探针 4：无代码（实验④ = 用本 repo 跑 MemFabric + 图模式 + MTP + 短序列参照）

探针 1/2 对两后端自动生效，无需切换。

## 3. 实验 → 探针 → 结论映射（判定表）

```text
实验①（两后端各跑，MTP+图模式+短序列，探针全程开启）：
  Mooncake pre_join 非零 & MemFabric 恒 0
      ⇒ E1 在 Mooncake 真实命中 + 解释 a（原语完成语义差异）同时成立
  两后端 pre_join 恒 0
      ⇒ E1 未实际命中；主因收敛 Mooncake 独有机制（看实验②/③ + H2 对照）
  两后端都非零但 MemFabric 精度正常
      ⇒ 窗口存在但未致错 ⇒ 指向可见性语义差异（D1/M2 方向，Mooncake 存储侧）
实验②：hash 不同 ⇒ P0-新 确诊；恒同 ⇒ 排除
实验③：immediate>0 ⇒ 解释 a 死；==0 ⇒ 解释 a 活
实验④：MemFabric 复现 ⇒ 前提推翻，E1 升回主因；不复现 ⇒ 差分真实
```

注意 E2 的单独信号：`pre_join` 非零**只出现在 tp_rank≠0**（tp0 恒 0）⇒ 纯跨 rank 问题；tp0 也非零 ⇒ E1 与 E2 并存。

## 5. 已知边界与注意

1. **观测即扰动**：探针在图内新增节点（每层 2 次比较 + D2H + host callback），三臂必须同探针设置对比；
2. MemFabric hostview 路径测量的是 host 侧 GVA 视图可见性，与算子的设备侧读取语义**近似同址但不完全等价**——结论以"MemFabric 侧恒 0 / 非零"的**对照差**为准，不读绝对值；
3. 探针 1 的 D2H 快照与比较回调使用与描述符路径**相同的 `aclrtLaunchHostFunc` 原语**——若 S1/H2（原语完成序）为真，探针自身也会受影响；好在两个探针同生共死，"探针看到的秩序"反而成为 S1 的间接观测量（若 slot_mapping hash 呈现"上一帧值"的模式，即为 S1 的直接证据）；
4. 环境变量按仓内惯例直接 `os.getenv`（与 `VLLM_ASCEND_SFA_INDEX_COPY_PROBE` 一致），上主线前应迁入 `envs.py`；
5. C++ 未在本机编译（无 NPU/ACL 头文件），首次容器启动若报编译错误，优先检查新增 include 与模板注册段。
