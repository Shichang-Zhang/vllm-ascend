### 2.2 机理链（本轮补强核对，成立）

- **planner 主动驱逐本 step 窗口 token**：`sparse_kv_offload.cpp:163-166`（`token >= stable_prefix_len` ⇒ `slot_to_token_row[slot] = -1; token = -1`）逐字属实；
- **只有"本行自己的 token"走正 plan（paired-copy 注入）**：`cpp:170-175`（`token == visible_seq_len - 1` 命中则 `encoded_plan_row[pos] = slot + 1`）；被驱逐后若被回填为 miss，则 `cpp:206-207` 的 `is_current_token` 特判再给正数；其余 miss 给负数；
- **miss 分配截断**：`cpp:195`（`assign_count = min(local_miss_count, evictable_count)`），未获得 slot 的 miss 保持 `plan = 0`；
- **算子侧 plan 语义**：`..._service_vector_mla.h:143-145` 声明、`:3211`（`IsSelectionPlanHit` → selection buffer）、`:3224-3240`（`externalHit` 为假时 `GetRealS2Idx` 走全量 KV，即 Host 池）；`plan>0` 命中、`plan<0` 从 Host 池读、`plan==0` 在 merge 循环里被 `if (!IsSelectionPlanUpdate(planValue)) continue;` 跳过；
- **写回目标与算子读取源同址**：`sfa_kv_offload.py:913-915` 的 `full_kv_cache` 来自 `manager.get_fused_overlap_cpu_kv_inputs` → `k_caches_cpu[layer_id]`，与 `_offload_new_kv_via_index_copy` 的 `flat_host_k` 同一张量。

⇒ 结论：**E1（TP0 自身同 step 读到未写完的行）与 E2（TP1-7 被提前放行的跨 rank 读）都是可证的竞态**，不是推测。

## 4. 对修复代码本身的逻辑复核（未发现需改）

### 4.1 关键 DAG 无环、无缺边（四态推演）

- 一层内：`compute.record_event(E) → save.wait_event(E) → save.index_copy_ K/V → compute.wait_stream(save) → fused_op`。compute→save 与 save→compute 两条边**不成环**（wait 节点在 index_copy 之后），FULL capture 可正常录图；
- FULL replay：Python 不重跑，图内 wait 节点保证顺序；
- eager：`use_side_stream=False`、Mooncake eager 分支不切流、flag 保持 False ⇒ 两处 wait 早退，空操作；
- piecewise replay：`_in_graph_runtime()=True` 触发 fork 并置 flag，算子路径传 `forward_context.capturing=False`，由 flag 兜住 ⇒ 正是 Fix D 的价值。

### 4.2 Fix A 的 WAR 隐患已被 Fix C 覆盖（重要不变式）

`_prepare_current_kv_index_copy_descriptors` 复用同一组 `d2h_src_idx_npu/d2h_dst_idx_npu` 缓冲。Fix A 让 **MTP 层再次刷新**这些缓冲，而 layer 0 的 `index_copy_` 在 save 流上**异步读取**它们，存在 WAR：

- 该 WAR 由"每层 join"消除：MTP 层刷新之前，中间每一层都会执行 `wait_for_current_kv_writeback`（offload 内 broadcast 前 + sfa 内 fused_op 前各一次），compute 已多次 join save 流 ⇒ layer 0 的读早已完成；
- **前提是这些 join 不被删除**。建议在 Fix A 处补一行注释固化该不变式（本轮仅记录，未改代码，避免扩大改动面）。

### 4.3 其余确认

- `getattr(self, "mtp_layer_id", -1)` 对 layer 0 语义不变（`0 in (0, -1)` 为真），单测/手工构造 manager 不炸；
- Fix C 的 join 放在 `VLLM_ASCEND_SFA_READY_BCAST` 开关**之外**（decode `:1502` 在 `:1503` 的 if 之前），即使关掉 broadcast 探针也仍会 join，正确；
- 标准分支 join 在 `tp_size > 1` 门内 ⇒ tp_size==1 时靠 sfa 的 join 兜底，亦正确；
- `wait_for_current_kv_writeback` 的 `use_fused_overlap`/`tp_rank` 早退保证 `current_kv_save_stream` 一定存在（仅 `use_fused_overlap` 时创建），无 AttributeError/空对象访问。
